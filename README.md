# SketchUp AI Massing Tool

A parametric architectural massing generator for SketchUp, built with Ruby.

## About

This project explores AI-assisted architectural design and 3D modeling workflows.

The tool allows architects and designers to generate basic building masses directly inside SketchUp.

## Features

- Parametric building dimensions
- Custom floor count
- Adjustable floor heights
- Automatic 3D geometry generation
- Individual floor groups
- SketchUp Ruby API integration

## Installation

1. Download the `ai_architectural_massing.rb` file.
2. Open SketchUp.
3. Open Window → Ruby Console.
4. Run the following command:

```ruby
load "PATH_TO_FILE/ai_architectural_massing.rb"
```

5. Find the tool under Extensions → AI Architectural Massing Tool.
